# Windows-Live-Notification-StreamerBot
This is a fork of [terrierdarts' Windows Live Notification (StreamerBot)](https://codepen.io/terrierdarts/pen/xxWbjYx) hosted on codepen. Over the years his site went down and doesn't look to be maintained anymore so I updated his code so it works locally again. 

(This assumes you already have OBS installed and connected to Streamer.bot)
To use it you need to:
Download the files somewhere on your computer
Add the html to your OBS sources
add an action in your Streamer.bot with the title WLN (nothing needs to be in it)
add another action that runs the WLN for a users first words.

I can update this later if people can't figure it out but I just updated the code because the site went down and the local version wasn't working anymore due to some changes in how Streamer.bot formatted its variables.
