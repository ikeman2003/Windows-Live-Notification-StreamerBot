# Windows-Live-Notification-StreamerBot

This is a fork of [terrierdarts' Windows Live Notification (StreamerBot)](https://codepen.io/terrierdarts/pen/xxWbjYx) hosted on CodePen. Over the years his site went down and doesn't look to be maintained anymore, so I updated his code so it works locally again.

## Setup

> **Note:** This assumes you already have OBS installed and connected to Streamer.bot.

1. Download the files somewhere on your computer.
2. Add the HTML file to your OBS sources.
3. Add an action in Streamer.bot with the title `WLN` (nothing needs to be in it).
4. Add another action that runs `WLN` for a user's first words.
