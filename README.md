# Windows-Live-Notification-StreamerBot
This is a fork of [terrierdarts' Windows Live Notification (StreamerBot)](https://codepen.io/terrierdarts/pen/xxWbjYx) hosted on codepen. Over the years his site went down and doesn't look to be maintained anymore so I updated his code so it works locally again. 

To use it you just need to add an action in your Streamer.bot with the title WLN then add another actions that runs it for a users first words. I can update this later if people can't figure it out but I just updated the code because the site went down and the local version wasn't working anymore due to some changes in how Streamer.bot formatted its variables.
